# Project scope

This project owns the Python/PyPI packages in `countrystatecity-pypi`.

- Keep implementation, pull requests, merges, and releases scoped to this repository.
- The npm ecosystem is handled separately. Do not modify or publish npm packages, or create, update, or merge PRs in `countrystatecity-npm`, unless the user explicitly requests npm work.
- Read upstream database exports as needed to assess Python compatibility. Report relevant npm implications without taking npm actions.
